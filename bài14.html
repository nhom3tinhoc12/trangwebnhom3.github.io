Luyện tập 2

Câu hỏi: Hãy liệt kê các thuộc tính CSS liên quan đến định dạng đoạn văn bản sau.

Câu trả lời:

  • Dòng đầu tiên sử dụng các định dạng: font-size, color.
  • Dòng thứ hai sử dụng các định dạng: text-align, color.
  • Hai dòng cuối sử dụng các định dạng: font-family, font-style.
Đi đến Vận dụng 1 (VD1) Quay về Luyện tập 1

VD1: Tìm hiểu thêm các thuộc tính phông chữ

Câu hỏi: Tìm hiểu thêm các thuộc tính phông chữ như font-variant và các thuộc tính dòng văn bản như letter-spacing, word-spacing và text-shadow.

Câu trả lời:

  • font-variant: Xác định kiểu viết hoa.
    + normal: chữ thường (mặc định)
    + small-caps: chữ viết hoa nhỏ
  • letter-spacing: Xác định khoảng cách giữa các ký tự.
    Ví dụ: letter-spacing: 2px;
  • word-spacing: Xác định khoảng cách giữa các từ.
    Ví dụ: word-spacing: 5px;
  • text-shadow: Tạo hiệu ứng bóng cho chữ.
    Ví dụ: text-shadow: 2px 2px 4px rgba(0,0,0,0.5);
Đi đến Vận dụng 2 (VD2) Quay về Luyện tập 2

VD2: Thiết lập 2 kiểu CSS khác nhau

Câu hỏi: Với bài đọc thêm Lịch sử CSS, hãy thiết lập hai tệp CSS khác nhau về phông chữ, cỡ chữ và màu chữ.

Câu trả lời:

/* style1.css */
body {
    font-family: Arial, sans-serif;
    font-size: 16px;
    color: #333;
}

h1 {
    font-family: "Times New Roman", serif;
    font-size: 28px;
    color: #990000;
}

p {
    font-family: "Courier New", monospace;
    font-size: 14px;
    color: #666666;
}

/* style2.css */
body {
    font-family: Verdana, Arial, sans-serif;
    font-size: 18px;
    color: #555555;
}

h1 {
    font-family: "Helvetica Neue", Arial, sans-serif;
    font-size: 32px;
    color: #006600;
}

p {
    font-family: Georgia, serif;
    font-size: 16px;
    color: #888888;
}
